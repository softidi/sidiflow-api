# SidiFlow

SidiFlow is a REST API for managing personal finances.

The project aims to provide a simple and extensible backend for tracking income, expenses, categories, payment methods, and financial activity.

## Overview

SidiFlow is being developed as a project focused on applying modern backend development practices using Java and the Spring ecosystem.

## Tech Stack
- Java
- Spring Boot 4
- Spring Security
- Spring Data JPA
- PostgreSQL
- Docker
- Maven

Additional technologies and tools may be incorporated as the project evolves.

## Project Status

SidiFlow is currently in the early stages of development.

The architecture, database model, API design, and initial development environment are currently being defined.
